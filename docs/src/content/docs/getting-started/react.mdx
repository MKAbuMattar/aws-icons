Typed, tree-shakeable React components. Dual ESM + CJS. React 17+.

```sh
pnpm add @aws-icons/react
```

## Usage

```tsx
import {Rocket, PartyPopper} from '@aws-icons/react/flat';
import {Fire} from '@aws-icons/react/modern';

<Rocket width={40} />              // decorative: aria-hidden
<Fire width={40} title="Fire!" />  // accessible: role="img" + aria-label
```

## Entry points

- Barrel per style (tree-shakeable): `@aws-icons/react/flat`, `/high-contrast`, `/modern`
- Single icon (no barrel at all): `@aws-icons/react/flat/rocket`

Component names are the PascalCased slug; slugs starting with a digit get an
`Icon` prefix (`1st-place-medal` → `Icon1stPlaceMedal`). Every component
forwards its ref and accepts all `SVGProps<SVGSVGElement>`.
