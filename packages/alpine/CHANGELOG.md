# @aws-icons/alpine

## 2.0.0

### Major Changes

- 09d4ad4: New framework packages, all generated from the same optimized SVG assets:

  - `@aws-icons/vue` — typed Vue 3 components, dual ESM+CJS
  - `@aws-icons/preact` — typed Preact components, dual ESM+CJS
  - `@aws-icons/solid` — SolidJS components with DOM/SSR/`solid`-condition builds
  - `@aws-icons/svelte` — Svelte 5 `Icon` component + tree-shakeable icon data
  - `@aws-icons/web-components` — framework-less `<aws-icon>` custom element
  - `@aws-icons/alpine` — Alpine.js `x-aws-icon` directive + `$awsIcon` magic
