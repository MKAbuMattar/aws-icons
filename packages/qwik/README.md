# @aws-icons/qwik

[AWS Architecture Icons](https://github.com/microsoft/fluentui-icon) as typed Qwik components (ESM only) — 3,145 icons in 5 sets.

## Install

```sh
pnpm add @aws-icons/qwik
```

## Usage

```tsx
import {Rocket} from "@aws-icons/qwik/flat";

<Rocket width={32} />
<Rocket title="Rocket launch" />  // accessible: role img + aria-label
```
